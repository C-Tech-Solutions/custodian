# Custodian 1.5.6

Custodian 1.5.6 is a corrective security release that strengthens update-package certificate revocation enforcement in addition to the publisher, archive, imported-scan, and release-provenance hardening prepared for 1.5.5.

The updater now performs an independent online certificate-chain check after Windows trust verification. If revocation status cannot be established, the update is blocked with a retryable error while the installed application remains usable. Successful chain results are reused only within the current package for files with the exact same signer certificate.

Release artifacts are produced through the protected signing workflow with Authenticode verification, an SPDX SBOM, lowercase SHA-256 checksums, GitHub artifact attestations, and immutable-release protection.

No evidence of compromise was identified during the security review.
