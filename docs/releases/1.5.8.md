# Custodian 1.5.8

Custodian 1.5.8 gives clear errors for scan files it can't open.

## Saved scans

Opening a file that isn't a Custodian scan, or a scan file with missing or invalid values, now fails with a message that says what is wrong. Before, it failed with a generic error or, for some bad values, opened with wrong sizes. Custodian checks:

- the file's format marker;
- that the scan's root path, engine, and start and completion times are present;
- that timestamps are valid;
- that every entry has the expected value types, no negative sizes or counts, and a full path.

## Updating from 1.5.6 or earlier

This update also brings everything in [Custodian 1.5.7](https://github.com/C-Tech-Solutions/custodian/releases/tag/1.5.7): faster scans, the session-wide Folder Map, and the fix for installs and updates with View > Always open as administrator turned on. If you use that setting on 1.5.6 or earlier, update from inside Custodian (Help > Check for Updates), or turn the setting off before you run a new `Setup.exe`.
