# Custodian 1.5.7

Custodian 1.5.7 makes scans faster, fixes installing and updating with View > Always open as administrator turned on, and tightens how saved scans and update packages are checked.

## Faster scans

- MFT scans read the `$MFT` directly from the volume and build the scan from its records, which also gives MFT scans last-write times. If the direct read cannot run, the scan falls back to the previous method and says why in its diagnostics.
- Recursive scans list each folder once and work through up to 8 folders at a time. The CLI's `--threads <n>` sets the number.
- The desktop app shows results as soon as a scan finishes, without first building the whole folder tree.

## Desktop app

- The Folder Map lists every drive and folder scanned in the session. Clicking a folder under another scan switches to it. Its rows fit the panel instead of scrolling sideways, and expanding a folder with thousands of subfolders no longer stalls the window.
- Lists no longer flash white or gray when you choose Relaunch as administrator, or when Custodian closes.

## Always open as administrator

The setting used to put a Windows "run as administrator" compatibility flag on `Custodian.App.exe`. That flag made the installer and updates fail with error 740. Custodian now asks for elevation itself as it starts, and moves an existing setting off the flag on first launch.

If you use this setting on an older version, update from inside Custodian (Help > Check for Updates), or turn the setting off before you run a new `Setup.exe`.

## Security

- Saved scans opened from a file are checked before use. Custodian rejects scan files with views or generated columns, and files whose folder links form cycles or point at missing folders.
- The terminal UI refuses Recycle and Copy to PC on scans opened from a file, as the desktop app already did.
- Every update package is fully verified before the updater uses it. Files in a package are checked by content as well as name, and the updater accepts only plain package file names from the release feed.

## Repository address

The repository moved to `github.com/C-Tech-Solutions/custodian`. Help > About, What's New and the update check use the new address. The old address redirects, so earlier versions keep updating.

Release artifacts are produced through the protected signing workflow with Authenticode verification, an SPDX SBOM, SHA-256 checksums, GitHub artifact attestations, and immutable-release protection.
