# Custodian 1.5.5

Custodian 1.5.5 is a security maintenance release that strengthens update-package trust, archive preflight limits, imported-scan mutation controls, and release provenance.

The updater now applies stricter publisher and file-identity checks to executable package contents, rejects malformed or unexpectedly structured archives before extraction, and fails closed when certificate revocation status cannot be established. Imported `.custodian-scan` files remain useful for review and export, but file mutations require a new live scan.

Release artifacts are produced through the protected signing workflow with Authenticode verification, an SPDX SBOM, lowercase SHA-256 checksums, GitHub artifact attestations, and immutable-release protection.

No evidence of compromise was identified during the security review.
