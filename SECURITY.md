# Security Policy

## Supported Versions

Security fixes are provided for the latest published Custodian release. Users should update to the newest installer or portable build from GitHub Releases before reporting an issue that may already be fixed.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub Security Advisories for this repository:

https://github.com/ctech1313/custodian/security/advisories/new

Include the affected Custodian version, installation type, Windows version, and concise reproduction steps. Do not include private file listings, customer data, access tokens, or other sensitive local-machine data unless it is strictly necessary and has been minimized.

We aim to acknowledge reports within 5 business days, keep reporters updated while a fix is being prepared, and publish remediation notes with the release that resolves the issue.

## Release Integrity

Custodian release and update packages must be built from trusted source, checksummed by Velopack, and Authenticode-signed by C-Tech Solutions LLC before publication. Unsigned or unexpectedly signed update packages are treated as release blockers.
